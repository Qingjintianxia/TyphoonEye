> 状态：已实施

## 1. 缺陷清单

| 编号 | 位置 | 缺陷 | 后果 |
|---|---|---|---|
| B-1 | `src/views/TyphoonMonitor.vue:52` | `t.latitude.toFixed(1)` 未做空值防御 | 缺坐标的台风导致整页渲染异常、白屏 |
| B-2 | `src/views/TyphoonDetail.vue:152` | 仅在 `onMounted` 取数；离开页面不清空 `currentTyphoon` | 路由参数变化时不刷新；二次进入闪现上一个台风数据 |
| B-3 | `src/views/Dashboard.vue:136` | 裸 `fetch` 无 `catch` | 接口失败静默，四张卡片显示 0，用户以为"没有台风" |

| B-7 | 各 store | 未接入统一请求层 | 无超时、无错误提示、无 401 拦截 |

## 2. 修复方案

### 2.1 空值安全（B-1）

一律通过 `utils/format.js` 的格式化函数输出，禁止在模板中直接调用 `toFixed()` 或读取 `.length`：

```vue
<!-- 修复前 -->
{{ t.latitude.toFixed(1) }}°N, {{ t.longitude.toFixed(1) }}°E
<!-- 修复后 -->
{{ formatCoord(t.latitude, t.longitude) }}
```

数组统一经 `safeList()` 读取。模板中涉及数字格式化的表达式视为代码审查红线。

### 2.2 详情页数据生命周期（B-2）

约定**路由参数驱动的取数模式**：

```js
watch(() => route.params.id, (id) => { id ? load(id) : reset() }, { immediate: true })
onUnmounted(() => typhoonStore.clearCurrent())
```

store 新增 `clearCurrent()` 动作，保证"进入页面 — 加载 — 离开清空"三段式闭环。
任何依赖路由参数的取数都必须用 `watch(..., { immediate: true })` 而非 `onMounted`。

### 2.3 请求异常处理（B-3 / B-7）

所有 store 改用 `utils/request.js` 的 `http`，并补齐 `error` 状态：

```js
const { loading, error, data } = useAsyncResource(() => http.get('/statistics'))
```

为降低重复，新增组合式函数 `src/composables/useAsyncResource.js`，统一封装
`loading / error / data / run / refresh`，供页面与 store 复用。
页面必须消费 `error` 并渲染可重试的错误态，不得静默。

### 2.4 路由守卫（B-4）

守卫增加两步校验：

1. token 存在性；
2. **token 未过期**（解析 JWT `exp`，见 `utils/token.js`）。

过期时清除 token 并携带 `redirect` 跳转登录；登录成功后回跳原路径。
解析失败（非法 token）按过期处理——宁可让用户重新登录，也不放行。

> 说明：客户端解析 `exp` 只是**体验优化**，真正的鉴权仍在服务端。
> 服务端 401 由请求层兜底，二者不冲突。

### 2.5 404 与错误边界（B-5）

- 新增 `src/views/NotFound.vue`，注册 catch-all 路由 `/:pathMatch(.*)*`。
- `App.vue` 增加 `onErrorCaptured` 全局错误边界（已在 P0-0 完成）。

### 2.6 交互与样式收敛（B-6）

- `AppLayout` 保留 `@click.outside`，删除手动事件监听与 `handleClickOutside`。
- 预警色标签 `.warn-*` 上提为**全局工具类**写入 `global.css`，
  四个组件内的重复定义全部删除（原 4 份 → 1 份）。

## 4. 验收标准

1. 构造一个 `latitude: null` 的台风数据，监控页正常渲染并显示 `—`，不白屏。
2. 从台风 A 详情跳到台风 B 详情，数据正确切换；退出再进入不闪旧数据。
3. 停掉后端服务，任意页面显示错误态 + Toast 提示，不出现静默 0 值。
4. 手动把 localStorage 中的 token 改为过期值，访问 `/monitor` 直接跳转登录且不闪烁。
5. 访问 `/no-such-page` 显示 404 页。
6. 全项目搜索 `.warn-` 样式定义，仅 `global.css` 一处。
7. `npm run build` 通过。
