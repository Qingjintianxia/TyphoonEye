# P0-4 底图切换为国内合规地图服务 规范

> 目标：移除境外底图与境外 CDN 依赖，改用具备国内测绘资质的「天地图」；无密钥时降级为示意海图占位。

## 1. 改造前的问题

| 位置 | 内容 | 问题 |
|------|------|------|
| `src/components/TyphoonMap.vue:55` | `basemaps.cartocdn.com` 境外底图 | 境外服务，国界线/台湾/南海诸岛画法不符合国家标准；国内不可达或极慢 |
| `index.html:7` | Leaflet CSS 走 `unpkg.com` CDN | 境外 CDN，不可达时地图样式全失 |
| `src/styles/global.css:1` | `fonts.googleapis.com` Inter 字体 | 境外 CDN，国内极慢/被墙，字体回退闪烁 |
| `TyphoonMap.vue` 内 `warningColors` / `warningLabel` | 重复定义预警色与文案 | 与 P0-0 常量重复，违反单一来源 |

## 2. 改造方案

### 2.1 新建 `src/config/map.js`
- 读取 `import.meta.env.VITE_TIANDITU_KEY`。
- `HAS_COMPLIANT_MAP`：有 key 为 true。
- `MAP_BASE_URL` / `MAP_LABEL_URL`：天地图 `DataServer` XYZ 接口（`T=vec_w` 矢量底图 + `T=cva_w` 中文注记层），带 `tk` 密钥与子域 `t0~t7`。
- 无 key 时 URL 为空，由前端降级。

### 2.2 `TyphoonMap.vue`
- 移除 cartocdn，按 `HAS_COMPLIANT_MAP` 选择：
  - 有 key → 叠加天地图矢量底图 + 注记层，并显示版权署名（合规要求）。
  - 无 key → 不加载任何外部底图，容器加 `.sea-chart` 样式（海面渐变 + 经纬网格 + 提示角标"未配置天地图密钥，当前为示意海图"）。
- 预警色/文案改用 `constants/typhoon` 的 `warningColor` / `warningLabel`，删除本地重复定义。

### 2.3 移除境外 CDN 依赖
- `index.html` 删除 unpkg 的 Leaflet CSS `<link>`；改为在 `main.js` 中 `import 'leaflet/dist/leaflet.css'`（走本地 npm 包）。
- `global.css` 删除 Google Fonts `@import`；`body` 改用系统中文字体栈（`PingFang SC` / `Microsoft YaHei` 等），不再依赖境外字体。

### 2.4 配置清单
- `.env.example` 新增 `VITE_TIANDITU_KEY=`。

## 3. 验收口径
- [ ] 全仓搜索 `cartocdn` / `unpkg` / `googleapis` / `cdn` 仅剩文档与 lock 文件中的历史记录，源码与 index.html 无境外运行期依赖。
- [ ] 未配置密钥时，地图渲染出海图占位（网格 + 提示），控制台无境外请求。
- [ ] 配置 `VITE_TIANDITU_KEY` 后，`npm run dev` 地图加载天地图矢量 + 注记层，并显示"© 天地图"署名。
- [ ] `TyphoonMap.vue` 内不再重复定义预警色/文案，统一引用 `constants/typhoon`。
- [ ] `npm run build` 通过，无境外资源请求（构建产物自包含 Leaflet CSS）。
