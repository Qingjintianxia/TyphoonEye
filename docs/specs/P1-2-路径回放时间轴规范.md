# P1-2 台风路径回放时间轴规范

## 1. 背景与问题

详情页的"路径时间线"目前是一张**静态表格**（`TyphoonDetail.vue:84-104`），逐行列出每个时刻的经纬度、风速、等级。它能提供数据，但无法回答用户真正关心的问题：

- 台风是怎么移动过来的？（表格读不出空间过程）
- 什么时候最强？（要自己比对数字）
- 接下来的预报路径走向？（实况与预报混在一条线里，无区分）

同时 mock 数据的 `path[]`（每个台风 3–8 个时刻点，含 `lat/lng/time/wind/level`）目前**只被用来画一条静态折线**（`TyphoonDetailMap.vue:62-77`），数据价值远未释放。

## 2. 目标与非目标

**目标**

- 时间轴回放：播放 / 暂停、拖动到任意时刻、倍速（0.5x / 1x / 2x）。
- 地图联动：已过路径实线高亮、预报段虚线；当前时刻标记与风圈随回放移动。
- **实况 / 预报区分**：以 `updateTime` 为分界，让用户一眼看出"已经发生的"和"预报的"。
- 强度演变曲线：风速随时间变化，数据点按强度等级着色，并与回放联动高亮当前时刻。

**非目标**

- 不做路径点之间的动画补间（按离散点推进即可，mock 点间距已足够密）。
- 不接入真实预报数据源（属 P2 实时化范围）。
- 不为每个路径点存储独立风圈半径（mock 的 `path[]` 无逐点风圈，当前沿用台风级 `radius7/10/12`，规范中标注此局限）。

## 3. 设计

### 3.1 状态归属：回放状态必须集中管理

新建 `src/composables/usePathPlayer.js`，持有 `index` / `playing` / `speed` 与 `play` / `pause` / `toggle` / `seek` / `reset`。

理由与 P1-1 一致：**播放器状态绝不散落到组件内部**，否则详情页与后续对比页（P1-3）会各写一套定时器逻辑。

### 3.2 实况 / 预报分界

- `realtimeIndex`（实况末点下标）= `path` 中 `time <= typhoon.updateTime` 的最后一项下标；若一个都不匹配，取 `path.length - 1`。
- 回放**初始定位在 `realtimeIndex`**（即"当前时刻"），用户点播放则从该点向后播放预报段；也可拖回开头重看全过程。
- 地图渲染：
  - `path.slice(0, idx+1)` → **实况段**：实线，主色（台风预警色）。
  - `path.slice(idx)` → **预报段**：虚线（`dashArray`），降低透明度。
- 这样即使不播放，静态查看时也能区分实况与预报——这是本次改造的一个独立收益。

### 3.3 地图改造（`TyphoonDetailMap.vue`）

新增 props：

- `currentIndex: Number`，默认 `-1`。`-1` 表示"不回放"，保持现状画完整路径（兼容监控页等其它调用方）。

渲染逻辑：

1. 实况折线（实线）+ 预报折线（虚线）。
2. 路径点 marker：回放时当前点放大并加白色描边。
3. 风圈：以**当前回放点**为中心（`L.circle(center, {radius: r*1000})`），沿用真实地理比例。
4. 保持 P0-4 的合规底图与无 key 降级（海图占位）行为不变。

### 3.4 强度演变曲线（`IntensityTrendChart.vue`，新建）

- **纯 SVG 手绘折线，不引入 echarts**。理由：`TyphoonTable` 已因 echarts 全量引入产生 1MB 大 chunk（已知待办），不应再放大该问题；且本图只是单序列折线，SVG 完全够用，风格也能与已有的 `WindRingChart.vue` 保持一致。
- X 轴：路径点顺序（等距）；Y 轴：风速 m/s。
- 折线下方渐变填充；数据点取 `levelColor(level)` 着色，直观反映强度变化。
- 当前回放点：放大 + 竖向指示线 + 数值标签。
- 空数据或仅 1 个点：展示空态，不绘制。

### 3.5 播放控制

- 用 `setInterval` 推进，间隔 = `BASE_INTERVAL / speed`（`BASE_INTERVAL = 900ms`）；倍速 0.5 / 1 / 2。
- 到达末点自动停止并停留，不循环（避免误导为"循环预报"）。
- 组件卸载、切换台风、path 变化时清理定时器并 reset。
- 拖动进度条时暂停自动播放，松手后保持用户选择的位置。

### 3.6 空值与边界

- `path` 为空 → 不渲染播放器与曲线，沿用"暂无路径数据"提示。
- `path.length === 1` → 禁用播放按钮（无可推进内容）。
- `time` 解析失败 → 按数组顺序展示，不抛异常（复用 `parseTime`，其对非法值返回 null）。

## 5. 样式与可达性

- 复用现有 CSS 变量；曲线与标记配色一律取 `levelColor()` / `warningColor()` 常量。
- 播放、倍速、进度条均用原生控件（`<button>` / `<input type="range">`），天然支持键盘与读屏。
- 进度条加 `aria-label` 描述当前时刻。
