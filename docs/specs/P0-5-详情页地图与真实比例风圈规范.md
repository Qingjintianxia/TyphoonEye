# P0-5 详情页单台风地图 + 真实比例风圈 规范

> 目标：补上详情页缺失的地图（原系统台风详情页无地图），并将失真的固定像素风圈改为真实比例。

## 1. 改造前的问题

| 位置 | 问题 |
|------|------|
| `src/views/TyphoonDetail.vue` | 详情页只有文字/卡片/时间线，**没有地图**——对台风系统而言最该有的东西缺失 |
| `TyphoonDetail.vue` 风圈半径卡片 | 固定像素圆环（160/120/80px），半径与真实 km 数值无比例关系，视觉上误导（如 7 级 380km 与 12 级 80km 的视觉大小差远低于真实比例） |

## 2. 改造方案

### 2.1 新建 `src/components/TyphoonDetailMap.vue`
单台风地图组件，复用 P0-4 的合规底图配置：
- 绘制该台风 `path` 路径折线 + 路径点（当前点高亮为白心）。
- 当前位置圆心标记（按预警色描边）。
- **真实比例风圈**：以 `center`（当前经纬度）为中心，用 `L.circle(center, { radius: radiusN * 1000 })`（半径单位米）绘制 7/10/12 级风圈，地理上准确。
- 无天地图密钥时同样降级为海图占位。

### 2.2 新建 `src/components/WindRingChart.vue`
纯 SVG 比例示意组件，替代固定像素圆环：
- 以最大风圈半径映射为 SVG 内半径上限，其余按真实 km 比例缩放，大圈在下、小圈在上。
- 右侧图例列出各风圈真实 km 数值。

### 2.3 `TyphoonDetail.vue`
- 在统计卡片后插入 `<TyphoonDetailMap :typhoon="typhoon" />`（全宽）。
- "风圈半径"卡片内改为 `<WindRingChart :typhoon="typhoon" />`，标题注明"真实比例"。
- 删除原固定像素圆环的模板与 `.radius-chart/.radius-ring` 等废弃样式。

## 3. 验收口径
- [ ] 详情页出现该台风的路径地图，可见路径线、当前位置与三个风圈。
- [ ] 风圈在地图上按真实 km 半径绘制（面积比 = 半径²比），不再是与数值无关的装饰圆。
- [ ] 风圈半径卡片的 SVG 示意与实际数值成比例，图例数值与数据一致。
- [ ] 无天地图密钥时，详情地图同样降级为海图占位，无境外请求。
- [ ] `npm run build` 通过。
