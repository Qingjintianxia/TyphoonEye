# P1-4 城市影响评估与距离测算规范

## 1. 背景与问题

系统目前能回答"台风在哪、多强"，但回答不了用户真正关心的问题：**对我有什么影响？**

- `affectedCities` 只是一个城市名字符串数组，没有坐标，无法做任何空间判断。
- 详情页只能看到"影响城市：福州、温州、宁波、上海"，看不出哪个城市最危险、什么时候最近、会不会进风圈。
- 应急、航运、公众等角色的核心诉求是：**距离多远、会不会进风圈、什么时候最近**。

mock 数据已具备计算条件：每个台风有 `latitude/longitude`、`path[]`（逐时刻经纬度）、`radius7/10/12`（风圈半径 km）。

## 2. 目标与非目标

**目标**

- 新建地理计算工具 `src/utils/geo.js`：球面距离、沿路径最近距离及时刻、风圈判定、风险定级。
- 新建沿海城市经纬度常量 `src/constants/cities.js`。
- 详情页新增"城市影响评估"面板：选城市 → 当前距离、**历史/预报最近距离及对应时刻**、落入哪级风圈、风险等级与建议。
- 默认一次性评估该台风 `affectedCities` 涉及的全部城市。

**非目标**

- 不做路径外推预测（只用已有 `path[]` 数据点，不预测未给出的时刻）。
- 不做人口 / 经济 / 灾损估算。
- 不做地形修正或投影转换（haversine 球面近似在百公里尺度上误差可接受）。

## 3. 设计

### 3.1 距离算法

使用 **haversine 球面距离**（地球平均半径 6371 km），而非平面欧氏距离。

理由：台风影响范围常跨 10 个经度以上，直接用平面近似会产生不可接受的误差（低纬度地区 1 经度 ≈ 111 km，高纬度显著变小）。

### 3.2 最近距离才是关键（本功能的核心价值）

只算"台风中心与城市的**当前**距离"是不够的，甚至是误导性的：

- 台风可能**昨天更近**（已过境，最危险时刻已经过去）；
- 也可能**明天更近**（尚未到达，最危险时刻还没来）。

因此必须遍历 `path[]` 每个点计算距离，取最小值，得到：

- `nearestKm`：最近距离
- `nearestPoint`：对应路径点（含时刻、风速、等级）
- `isFuture`：该时刻是在当前时刻之前（已发生）还是之后（预报）

这样用户能同时得到"最近有多近"和"什么时候最近"。

### 3.3 风圈判定

- `radius7/10/12` 为半径（km），`distance <= radius` 即视为在该级风圈内。
- 风圈是**同心圆且 12 级最小**，因此可能同时落入多级 → 取**最内圈（最高级）**作为结论。
- `radius` 为 `0` / `null` 表示该级风圈不存在，跳过判定。

### 3.4 风险定级

优先依据**最近距离**与风圈的包含关系：

| 条件 | 等级 | 预警色 |
|---|---|---|
| `nearestKm <= radius12` | `extreme` 极高 | 红 |
| `nearestKm <= radius10` | `high` 高 | 橙 |
| `nearestKm <= radius7` | `medium` 中 | 黄 |
| `nearestKm <= radius7 * 2` | `low` 低 | 蓝 |
| 其它 | `none` 无 | — |

**兜底规则**：若三级风圈半径全部缺失（如弱热带风暴只有 7 级风圈），退化为按距离阈值判定——`<=100km` 高、`<=300km` 中、`<=600km` 低、否则无。避免出现"没有任何风圈数据就永远显示无风险"的假阴性。

风险等级统一映射到预警四色，复用全局 `.warn-tag warn-{level}`，不新增配色体系。

### 3.5 城市坐标表

`src/constants/cities.js` 导出 `CITY_COORDS`（`{ name, lat, lng }`）与 `findCity(name)`。

- 覆盖**大陆沿海主要城市**及**中国香港、中国澳门**（命名遵循一个中国原则，不作为独立国家/地区列出）。
- 未收录的城市 `findCity` 返回 `null`，UI 明确提示"暂未收录该城市坐标"，**绝不臆造坐标、绝不返回 0 距离**——错误的距离比没有距离更危险。

### 3.6 组件：`CityImpactPanel.vue`

- 顶部：城市选择器（下拉），默认包含该台风 `affectedCities` + 全部内置城市。
- 当前城市评估卡：当前距离、**最近距离 + 对应时刻 + 已发生/预报**、风圈状态、风险徽标、建议文案。
- 下方：该台风 `affectedCities` 的逐城评估摘要（距离 / 风险色标），便于横向比较哪个城市最危险。
- 建议文案随风险等级变化（如极高 → "处于 12 级风圈影响范围，请立即做好防风准备"）。

### 3.7 空值与边界

- 台风无 `path` → 只算当前中心距离，并标注"无路径数据，无法计算最近距离"。
- 台风 `latitude/longitude` 缺失 → 退化用 `path` 末点；都缺则不评估。
- 城市未收录 → 明确提示，不显示距离数字。
- `affectedCities` 为空 → 提示"暂无明确影响城市"，仍可手动选择其它城市评估。
