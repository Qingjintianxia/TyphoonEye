# P1-7 天地图底图接入与地图层统一规范

## 1. 背景与问题

P0-4 完成了合规底图的**架构**改造（去 cartocdn、接天地图、无 key 降级海图占位），但底图一直没真正跑起来，且留下三处结构性问题：

1. **没有密钥** —— `VITE_TIANDITU_KEY` 未配置，项目根也没有 `.env`，三个地图组件全部走「示意海图」降级态，用户从未见过真实底图。密钥现已提供于 `src/assets/tianditu.md`。
2. **底图创建逻辑三份重复** —— `TyphoonMap.vue`、`TyphoonDetailMap.vue`、`TyphoonCompareMap.vue` 各自写了一遍 `L.tileLayer(MAP_BASE_URL, ...)` + `L.tileLayer(MAP_LABEL_URL, ...)`。违反项目「单一数据源」约定：改一次底图参数要动三个文件，漏一处就出现「同一个系统里有的地图是新版、有的是旧版」。
3. **缩放上限过低** —— `maxZoom: 12` 把用户锁在省级视野，看不了城市级落区；而天地图矢量底图实际支持到 18 级。

## 2. 目标与非目标

**目标**

- 接入真实天地图底图，让三个地图组件都显示合规矢量底图（不再是海图占位）。
- 底图创建收敛到 `src/config/map.js` 一处，三个组件只调用、不重复实现。
- 提供**矢量 / 影像 / 地形**三种底图切换，并补比例尺控件。
- 完成可验证的测试：瓦片接口连通性 + 浏览器实际渲染截图。

**非目标**

- 不做底图服务的后端代理（天地图浏览器端 key 本身就是公开的，代理只会增加复杂度）。
- 不做离线瓦片 / 自建瓦片服务。
- 不引入除了 Leaflet 自带控件之外的地图交互库。

## 3. 设计

### 3.1 密钥存放位置：`.env`，不写进源码

- 写入项目根 `.env`：`VITE_TIANDITU_KEY=...`，由 `src/config/map.js` 经 `import.meta.env` 读取——沿用 P0-4 已设计好的机制，不新增读取路径。
- 同步新增 `.gitignore`，把 `.env`、`node_modules`、`dist` 排除。**密钥属敏感信息，不得随目录打包/外发。**
- **注意**：修改 `.env` 后必须**重启前端 dev server**，`import.meta.env` 在启动/构建期注入，热更新不会重读。

> 关于「天地图浏览器端 key 会出现在产物 JS 里」：这是天地图浏览器端 key 的既定使用方式（它按域名配额校验，本质上公开）。真正需要保密的是后端密钥（JWT_SECRET），二者不能混为一谈。

### 3.2 底图注册中心：`src/config/map.js`

新增底图类型表，每个类型包含底图与注记两个图层参数：

| 类型 key | 显示名 | 底图 T= | 注记 T= |
|---|---|---|---|
| `vector` | 矢量 | `vec_w` | `cva_w` |
| `image` | 影像 | `img_w` | `cia_w` |
| `terrain` | 地形 | `ter_w` | `cta_w` |

- 瓦片 URL 模板：`https://t{s}.tianditu.gov.cn/DataServer?T=<T>&x={x}&y={y}&l={z}&tk=<KEY>`
- 子域 `t0`~`t7`（`subdomains: '01234567'`），提高并发加载能力。
- 缩放范围：`minZoom: 3`、`maxZoom: 18`（天地图矢量/影像/地形均支持 1–18；原 12 上限是保守设置，已实测 14 级有真实瓦片）。
- 导出 `createBaseTileLayers(L, map, typeKey = 'vector')`：**唯一**的底图创建入口，内部负责加底图 + 注记两层，并返回已加入的图层数组，供后续切换时移除。
- 导出 `switchBaseLayer(L, map, currentLayers, typeKey)`：先移除旧层再建新层，保证切换不留残影。
- 保留 `HAS_COMPLIANT_MAP` 降级开关：无 key 时 `createBaseTileLayers` 直接返回空数组，组件照常显示海图占位——**绝不回退境外底图**。

### 3.3 组件改造（去重）

`TyphoonMap.vue` / `TyphoonDetailMap.vue` / `TyphoonCompareMap.vue`：

- 删除各自的 `L.tileLayer(MAP_BASE_URL...)` / `L.tileLayer(MAP_LABEL_URL...)` 代码块。
- 改为 `baseLayers = createBaseTileLayers(L, map)`。
- 组件内不再持有 `minZoom/maxZoom/subdomains/attribution` 等底图参数——这些只属于 `config/map.js`。

### 3.4 底图切换控件

在监控页主地图（`TyphoonMap.vue`）右上角图例区内加一组「矢量 / 影像 / 地形」切换按钮：

- 只在 `HAS_COMPLIANT_MAP` 为 true 时渲染（无 key 时无底图可切）。
- 切换时调用 `switchBaseLayer`，选中态用 `--blue` 高亮。
- 同时给三个地图组件加 `L.control.scale({ imperial: false })` 比例尺——台风影响范围判断需要距离感，比例尺是刚需。

## 7. 风险与注意事项

- **密钥安全**：`.env` 已加入 `.gitignore`。若日后纳入版本管理，务必确认 `.env` 未被提交。
- **配额**：天地图按 key + 域名做调用配额，两个 key 中第一个为主用，第二个为备用（已实测同样有效）。
- **maxZoom 18** 时部分海域/境外区域可能返回空白瓦片（实测 z18 某块仅 103 B，属正常覆盖边界），非配置错误。
