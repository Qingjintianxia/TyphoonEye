# P2-7 城市点击定位规范

## 1. 背景与问题

用户在台风详情页 / 监控页点击城市时"没反应"。代码核查结论：

- `TyphoonDetailMap.vue`、`TyphoonMap.vue` **只画台风路径与风圈，从不渲染城市点**；
- `CityImpactPanel.vue` 的「影响城市评估」行是纯展示 `div`，**没有 click handler，也没有 `cursor:pointer`**；
- `FenceAlerts.vue` 告警条目里的城市名是 `span`，同样不可点；
- 全项目搜 `flyTo / setView / locate`，只有"按台风定位"，没有任何"按城市定位"。

即：这不是"定位算错"，而是**交互链路缺失**——城市在 UI 上出现，却没有与地图联动。
用户点得下去（元素就在那里），却得不到反馈，比"没有这个功能"更容易被当成 bug。

## 2. 目标

让**所有出现城市名的地方都能一键把地图定位到该城市**，且在无地图的页面给出等价的跳转行为，
保证"点了一定有反馈"。

| 位置 | 行为 |
| --- | --- |
| 详情页「城市影响评估」城市行 | 点击 → 详情地图 flyTo + 城市标记；再点一次取消定位，回到台风视角 |
| 详情页「城市影响评估」下拉切换 | 切换即定位（无需再点一次） |
| 监控页「地理围栏告警」城市名 | 点击 → 监控地图 flyTo + 城市标记 |
| 预警中心「地理围栏告警」城市名 | 无地图 → 跳 `/monitor?focus=<城市名>` 并定位（深链） |
| 城市未收录坐标 | 不定位，toast 提示"该城市暂未收录坐标"，避免静默无反应 |

## 3. 设计约束

1. **定位不能被重绘抢回**：`TyphoonDetailMap.render()` 每次重绘都会 `map.setView(ringCenter, 5)`，
   若不处理，回放播放/切换台风时视图会被拽回台风中心。
   → 引入 `focusActive` 内部标志，聚焦态下 `render()` **跳过 setView**。
2. **城市标记必须可回收**：标记存独立数组 `focusLayer`，重新定位/取消定位时先移除旧的，
   不能混进 `layers`（否则会被 `clearLayers()` 误删或重复叠加）。
3. **未收录城市绝不臆造坐标**：`findCity()` 返回 null 时**只提示不定位**（`constants/cities.js` 既有铁律）。
4. **可点击元素必须是可聚焦控件**：用 `button` 而非 `div`，带 `aria-label` 与 `:focus-visible` 样式，键盘可达。
5. **单一数据源**：城市坐标只从 `constants/cities.js` 取，组件不硬编码经纬度。

## 4. 改动清单

| 文件 | 改动 |
| --- | --- |
| `src/components/TyphoonDetailMap.vue` | 新增 props `focusCity` / `focusSeq`；watch 后 `flyTo` + 城市标记；`focusActive` 期间 `render()` 不 `setView`；`focusCity` 为空则移除标记并复位 |
| `src/components/TyphoonMap.vue` | 新增 props `focusCity` / `focusSeq`，同上（监控页） |
| `src/components/CityImpactPanel.vue` | 城市行改为 `button`，`@click` emit `locate`；选中行高亮；下拉切换 emit `locate`；未收录城市 emit 空并提示 |
| `src/components/FenceAlerts.vue` | 告警条目城市名改为 `button`，emit `locate`（城市对象） |
| `src/views/TyphoonDetail.vue` | 持有 `focusCity`，接收 `@locate`；未收录时 toast；再次点同一城市取消 |
| `src/views/TyphoonMonitor.vue` | 接收 `@locate` → 传 `focusCity` 给 `TyphoonMap`；`onMounted` 读 `?focus=` 深链定位 |
| `src/views/AlertCenter.vue` | 无地图 → `router.push({ path: '/monitor', query: { focus: name } })` |

`focusSeq` 的作用：同一个城市被再次点击（用于取消 → 再次定位）时，prop 对象内容不变、watch 不触发；
用一个自增序号强制触发定位。这是"取消后再定位"能工作的关键。

## 5. 验收

| 场景 | 期望 |
| --- | --- |
| 详情页点击城市行 | 地图中心变为该城市、出现城市标记、行高亮 |
| 详情页回放播放中 | 视图**不**被拽回台风中心 |
| 详情页再次点同一城市 | 取消定位，标记消失，视图回到台风 |
| 下拉切换城市 | 同步定位 |
| 监控页点围栏告警城市 | 监控地图定位 |
| 预警中心点围栏告警城市 | 跳转 `/monitor?focus=xx` 并定位 |
| 未收录坐标城市 | toast 提示，视图不变 |
| 键盘 Tab + Enter | 可聚焦并触发定位 |

自动化：`%TEMP%/typhoon_city_locate_e2e.mjs`（CDP：断言点击后地图中心 lat/lng 与目标城市一致）。

## 6. 回归提示

- 新增"地图上打点"必须在**独立图层数组**中管理，禁止复用 `layers` / `pathLayers`。
- 任何新增的 `map.setView()` 都要先问：会不会抢走用户的聚焦视角？
